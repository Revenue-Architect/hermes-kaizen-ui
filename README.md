# Hermes Kaizen UI

Two plugins for Hermes Desktop and the Webapp. None of them changes Hermes itself.

| Plugin | What it does | Install |
|---|---|---|
| [`packages/theme`](packages/theme) | The Kaizen theme and its card navigation | `hermes plugins install Revenue-Architect/hermes-kaizen-ui/packages/theme` |
| [`packages/views`](packages/views) | Interactive A2UI and OpenUI views and live dashboards in chat, one toolset per spec | `hermes plugins install Revenue-Architect/hermes-kaizen-ui/packages/views` |

Each needs Hermes v0.23.0 or later. After installing, run `hermes plugins enable <name>` and turn on its Desktop half in Capabilities > Plugins.
